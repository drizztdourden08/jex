# Jex v0.2.0

Remote AI models, a reworked Library and Settings, and fixes for the app hanging without a window.

## Features

- **Claude and OpenAI models.** Add an Anthropic or OpenAI API key in Settings and pick a remote
  model in the AI drawer. Remote models use the same tools as the local one, and the library
  query runs on the active model. Keys are encrypted with Electron `safeStorage` and sent only to
  their own provider.
- **Reasoning effort per chat.** A select in the chat footer sets the effort for remote models.
- **Library list mode.** Switch between cards and a compact list with the game's details beside it.
  Sort, display mode and totals now sit in the filter bar, which takes less room.
- **Sync in the title bar.** Library sync progress and errors live in a popover behind a title-bar icon.
- **Icon side nav.** The side nav shows an icon per page, starts collapsed, and opens with the
  chevron on its edge.
- **Settings.** Grouped into Library, AI assistant and General.

## Fixes

- Jex no longer hangs without a window after a corrupted `library.db`.
- The library database is written at most every 15 seconds during a sync, atomically, and on quit,
  instead of on every few games.
- The Library refreshes while the sync and metadata enrichment run.
- The window keeps its glass transparency when maximized, restored or fullscreen.
- Many UI fixes: failed calls no longer break the AI drawer, model picker or Settings; the
  maximize button stays in sync; IME Enter no longer sends a chat message.

## Notes

- The AI engine is a new version (plugin API 2); Jex downloads it the first time you open the
  AI drawer.
