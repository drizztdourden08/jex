# Jex v0.2.3

## New

- **The AI can really drive the Store tab.** Its clicks are now real mouse clicks, so Steam's
  own buttons, filters and menus respond the way they do for you. After every click or
  checkbox change it sees whether the box is now on or off, it can set many boxes in one step,
  it can click a spot it sees in a screenshot, and it can hover to open menus. It can also take
  more steps in one request, so changing ten store preferences no longer stops halfway.
  Purchases, checkout, sign-in, payment pages and password fields stay blocked.
- **Running games are detected.** Jex notices a game that is running, however you started it,
  and Play turns into **Stop**. Stop asks first and only closes processes running from that
  game's own folder.
- **Settings has tabs.** Library, AI assistant and General, instead of one long page. Sections
  that are still loading show a spinner instead of appearing late.
- **Troubleshoot the AI engine yourself.** Settings shows the installed and published engine
  versions and the last update check, with Check for updates, Open log and Reinstall engine.
- **Remove add-ons.** An installed add-on such as CUDA can be removed from Settings. Deleting
  a downloaded local model now asks first and refuses the model you are using.
- **A tidier chat footer.** Permission on the left; model, effort and a small context ring on
  the right. Click the ring to see context used, this chat's tokens and an estimated cost for
  cloud models.
- **Styled confirmations.** Stop, delete, remove and reinstall now ask in Jex's own dialog
  instead of a plain system popup.

## Fixes

- **AI engine updates are reliable.** Jex waits longer for the update check at startup, keeps
  trying in the background if it times out, and tells you when a restart will install the
  update. The large CUDA add-on is never re-downloaded on its own; Settings shows when it has
  an update and you choose when to get it.
